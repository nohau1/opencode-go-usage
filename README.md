# opencode-go-usage

OpenCode Go usage in your TUI: rolling 5h, weekly and monthly limits with reset countdowns. One click or `alt+u`.

Модальное окно с расходом подписки **OpenCode Go** прямо в TUI OpenCode:
rolling 5 часов, неделя и месяц, с процентами и временем до сброса.

## Как открыть

- Кликнуть по чипу `[Go 5ч 6%]` в футере (на главном экране и в сессии).
- Нажать `alt+u`.
- Ввести `/gousage` или `/go-usage` в промпте.
- Найти в палитре команд (`ctrl+p`) пункт **«OpenCode Go: расход подписки»**.

Закрыть: клик по `✕` в правом верхнем углу, клик вне окна или `Esc`.

В заголовке рядом с `✕` видно, сколько дней осталось до конца подписки.
Отдельного поля «дата окончания» API не отдаёт, поэтому значение считается
по дате сброса месячного лимита — она обычно совпадает с датой продления. Если до
конца ≤ 7 дней, счётчик становится жёлтым, если ≤ 3 — красным.

## Установка

```bash
git clone https://github.com/nohau1/opencode-go-usage.git \
  ~/.config/opencode/plugins/opencode-go-usage
```

Добавьте абсолютный путь в `~/.config/opencode/cli.json` (замените
`/home/you` на свой домашний каталог):

```json
{
  "plugins": ["/home/you/.config/opencode/plugins/opencode-go-usage"]
}
```

`cli.json` — глобальный конфиг TUI, поэтому плагин работает во всех
проектах. Для проектного `opencode.json` он тоже подойдёт, если плагин нужен
только в одном проекте. После сохранения конфига выполните `/reload` или
перезапустите TUI.

Плагин не требует сборки: OpenCode загружает `src/tui.tsx` напрямую.

## Совместимость

- OpenCode **2.1.4+** — проверено.
- На **2.2.0+** сначала используется серверный `client.usage.limits`.
- На **2.1.x** используется `https://opencode.ai/zen/go/v1/usage` с ключом из
  `auth.json` (см. ниже).

## Настройки

Опции передаются объектом в `cli.json`:

```json
{
  "plugins": [
    {
      "package": "/home/you/.config/opencode/plugins/opencode-go-usage",
      "options": {
        "keybind": "alt+u",
        "barCells": 18,
        "showFooter": true,
        "refreshSeconds": 120
      }
    }
  ]
}
```

| Опция            | По умолчанию | Что делает                                              |
| ---------------- | ------------ | ------------------------------------------------------- |
| `keybind`        | `alt+u`      | Клавиша открытия. `false` — отключить привязку.          |
| `barCells`       | `18`         | Ширина полосок в символах.                              |
| `showFooter`     | `true`       | Показывать кликабельный чип в футере.                    |
| `refreshSeconds` | `120`        | Как часто обновлять чип (секунды, минимум 10).          |

Пока окно открыто, данные обновляются каждые 20 секунд.

## Откуда берутся данные

Плагин пробует два источника по порядку:

1. **Серверный эндпоинт** `client.usage.limits` (OpenCode 2.2.0+). Ключ не
   нужен: используется вход в Console, работает и с удалённым сервером.
2. **`https://opencode.ai/zen/go/v1/usage`** с API-ключом Go. Ключ ищется в:
   - `OPENCODE_GO_API_KEY`;
   - настройках плагина (если вы вводили его через `/gousage key`);
   - `~/.local/share/opencode/auth.json` — тот же ключ, который пишет
     `opencode auth login`, поэтому на локальной машине ничего настраивать не
     нужно.

Если ключа нет, при первом открытии окно предложит его вставить. Ключ
сохраняется в локальном хранилище плагина и отправляется только на
`opencode.ai`.

Сменить или сбросить сохранённый ключ:

```
/gousage key        # откроет защищённый ввод ключа
/gousage key reset  # удалить ключ из настроек плагина
```

`reset` удаляет ключ из настроек плагина; снова используется `auth.json`.
Переменная окружения `OPENCODE_GO_API_KEY` имеет приоритет над обоими
хранилищами — её удобно использовать в скриптах и на удалённых машинах.

## Приватность

- Никакой телеметрии и внешних серверов, кроме `opencode.ai`.
- Ключ не логируется.
- Куки и токены других провайдеров не читаются.

## Разработка

```bash
npm install
npm run typecheck
```

Точка входа — `src/tui.tsx`, экспорт `./tui` в `package.json`. Плагин
использует только документированный API `@opencode/plugin/tui`: `keymap`,
`ui.slot`, `ui.dialog`, `storage`.
